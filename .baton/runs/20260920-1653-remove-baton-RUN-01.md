## Changes

- `docs.go`: embedded `bootstrap/CLAUDE.md` alongside `bootstrap/AGENTS.md`
  (single `bootstrapInstructions` embed.FS) and added
  `ShippedInstructionFile(name)` for Decision 3's whole-file comparison.
  `ActiveBlock()` unchanged.
- `internal/baton/merge.go`: added `computeRemovedContent(target)`, the
  seam-rule computation for cutting a `<baton-rules>` block out of a file
  (block-last, block-in-the-middle, and nothing-but-the-block cases).
  `replaceBlock`/`computeReplacedContent` untouched.
- `internal/baton/pause.go`:
  - added `classifyInstructionFile(path)` (per-file classification: active,
    paused, unknown, or absent-with-no-error) and rewrote `projectBlockState`
    on top of it per Decision 6 (a present file with no block is no longer an
    error; disagreement between present files still is, with a message naming
    which file lacks the block).
  - extended `writeInstructionBlocks` to take one planned content per file,
    where `nil` means delete; the rollback loop now recreates a deleted file
    from its original bytes exactly as it restores an overwritten one.
  - added `spliceBlockIntoFiles` (splices one block into every file via
    `computeReplacedContent`, used by pause/resume) and updated their call
    sites.
  - added `removedUpdateMessage` (the Decision 6 refusal `update --apply`
    gives in a removed project) and updated `runPause`/`runResume`'s
    `blockAbsent` messages per Decision 9.
- `internal/baton/lint.go`: `checkAgentBlocks` gained the fourth row (no
  block in any present file -> `OK: Baton is not in effect here...`) and an
  explicit disagreement error naming which file lacks a block; it no longer
  returns silently when neither instruction file exists (closes REVIEW-01's
  N3). `Lint()` gained a removed mode that skips every check requiring
  installed machinery (managed documents, VERSION, the binary, its
  executable bit and checksum, `bin/`, `templates/`) and keeps every check
  over the record (`GUIDANCE.md`, `LESSON-LEARNED.md`, `runs/`,
  `lesson-learned/`, the timeline, the legacy-directory checks, both
  Git-tracking checks narrowed to `keptTrackedPaths`, and `checkLog`).
- `internal/baton/artifact.go`: `templatePlaceholderTokens` and
  `checkArtifact` gained a `removed bool` parameter. Only lint's `checkLog`
  passes `removed=true`, in which case a missing `.baton/templates/`
  directory yields an empty token set instead of an error, so lint can check
  a removed project's history without failing on every recorded artifact.
  The public `CheckArtifact` and every other caller still fail closed on a
  missing templates directory (existing `TestPlaceholderCheckFailsClosedWithoutTemplates`
  is unchanged and still passes). This is one behavior not named in the plan
  by number; it surfaced as a real gap while testing V4 (see Unresolved Risks).
- `internal/baton/update.go`: `update --apply` now also refuses in a removed
  project (Decision 6), printing/erroring `removedUpdateMessage` beside the
  existing paused-message handling.
- `internal/baton/app.go`: dispatches `remove` to the new command, added it
  to `usage()` under "Configure and maintain", and deliberately left it out
  of `refusesWhilePaused`.
- `internal/baton/remove.go` (new): `runRemove` implementing Decisions 1-5 --
  argument parsing (`--apply`, `--force`, `--purge`), `buildInstructionPlan`
  (per-file classification, whole-file-shipped detection via
  `ShippedInstructionFile`, seam computation via `computeRemovedContent`, and
  a combined refusal naming every file with an unrecognised block),
  `buildRemovePlan` (Decision 1's table: managed docs by content comparison,
  `VERSION` always deleted, templates by shipped name, `bin/` contents, and
  the permanently-kept record paths), `purgePrecondition` (Decision 2's Git
  guard: every path under `.baton/` that Git does not ignore must be tracked
  and clean, else refuse naming each offending path; not a Git repo always
  refuses), the dry-run report, and the apply path in Decision 4's order
  (instruction files, then non-bin `.baton/` deletions, then the timeline
  `REQUEST -> RUN_DONE` append, then `bin/` last). `--purge` deletes
  `.baton/` in full after the instruction files are spliced and appends
  nothing to the timeline, per Decision 2.
- `.baton/PROTOCOL.md` and `bootstrap/.baton/PROTOCOL.md`: added the one
  Decision 8 sentence to the existing pause paragraph in "Git And Updates",
  identical in both copies (verified with `diff`).
- `README.md`: added a "제거" subsection after "일시 중지와 재개" describing
  the command, what is deleted/kept, `--purge` and its Git precondition, and
  that there is no `resume` from it.
- `internal/baton/pause_test.go`: updated the one existing call to
  `writeInstructionBlocks` for its new per-file signature
  (`spliceBlockIntoFiles`), which was the only test fixture the signature
  change touched; no fixture asserted the old "AGENTS.md missing
  <baton-rules> block" error text; none needed changing.
- `internal/baton/remove_test.go` (new): tests for V1-V6 and the five
  Director-emphasis items, listed under Validation below.
