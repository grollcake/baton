## Acceptance

- A stopping session can seal `.baton/HANDOFF.md`, and the next session finds it
  from `baton status` alone, marked live, superseded, or unreadable. That is the
  goal the plan set.
- The record carries only what dies with the session. Everything a resuming
  session can read for itself the binary stamps: the log line, and the delegate
  state for every open task, including which stage was cut off and whether its
  artifact is missing, a checkpoint, or complete but not yet appended. Director
  writes only branch strategy, unrecorded decisions, and next intent.
- The stamp cannot be forged at seal time: a hand-written `## Delegates` is
  refused with the file left byte-identical, and a body carrying the marker is
  overwritten whole.
- Existing `status` behaviour is unchanged, compared byte for byte against a
  binary built from HEAD across every task id and eight synthetic states.

## Lesson Candidates

- A binary that overwrites itself in place is killed on every exec afterwards:
  macOS caches the ad-hoc signature for that path, so `go run
  ./cmd/build-release` left `.baton/bin/baton` exiting 137 for every subcommand.
  It cost two rounds, and both times the Executor reported it as a host problem
  because a byte-identical copy elsewhere ran fine. Whether this qualifies is
  the user's call once `build-release` is fixed, since the fix removes the way
  it happens.

## Remaining Nits

- The seal is not tamper-evident after the fact: editing a sealed record is
  undetected and still reads live. A stamped digest would close this along with
  the `Date:` and `Log Line:` variants of it.
- `revert-check` on `events.go` reports `pins=none` because the revert fails to
  build. The FEEDBACK next-gate string, now feeding the stamped block, has no
  assertion.
- `delegateArtifactState`'s `incomplete` state is verified by hand but has no
  test.

## Residual Risks

- Staleness rides one axis, the log advancing. A handoff sealed over work that
  appends no further event stays live until `--clear`.
- `go run ./cmd/build-release` still leaves the installed binary unexecutable on
  macOS until it is re-signed or replaced. Fixing it is the next task.
