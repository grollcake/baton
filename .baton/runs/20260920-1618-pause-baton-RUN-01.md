  `blockStatus` classification (`active | paused | absent | unknown`);
  `classifyBlock`, `projectBlockState` (equality required only between
  instruction files that exist, gap A); `writeInstructionBlocks` (computes

  `refusePausedForUpdate` / `refuseIfPaused`; `runPause` and `runResume`.

  `refusesWhilePaused` map and one gate check in `Run`'s dispatch, before the
  switch, covering `append`, `new-round`, `feedback`, `gate`,
  `prompt`/`subagent-prompt`, and `await`. `update` and `merge-agent-block`
  are deliberately not in the map (Decision 4a). Added both commands to
  `usage()`.

  once; the dry run prints it (still exits 0) and `--apply` returns it as an
  error before `preflightUpdate` runs.

  three-way table (active / paused / matches neither), requiring equality

  gap B).
- `internal/baton/events.go`: extracted `reportOpenTasks`'s open-task
  detection into `openTaskList` (pause.go) so `status --open`, `pause`, and
  `resume` share one implementation (Decision 5); output format unchanged.
- `.baton/PROTOCOL.md` and `bootstrap/.baton/PROTOCOL.md`: added the one
  Decision 8 sentence to "Git And Updates" (identical in both copies).
- `.baton/HOW-TO-UPDATE.md` and `bootstrap/.baton/HOW-TO-UPDATE.md`: added
  the one Decision 8 line as new Step 0 (identical in both copies).
- `README.md`: added a short "일시 중지와 재개" section under 설치와 업데이트.
- Tests: `internal/baton/pause_test.go` (new) and updates to
  `internal/baton/coverage_more_test.go`'s `TestAgentBlockLintBranches` to
  use the real shipped active/paused blocks instead of synthetic text
